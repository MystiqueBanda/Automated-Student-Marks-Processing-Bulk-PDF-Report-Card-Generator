# Automated-Student-Marks-Processing-Bulk-PDF-Report-Card-Generator
Automate calculation, validation, grading and PDF report-card generation with two-tier exception handling and an audit log, finishing a batch in under 0.5 seconds.

How to run:

1. Download the SAL project
2. Open Launch_Dashboard.bat
